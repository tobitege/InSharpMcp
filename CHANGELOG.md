# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-06-17

### Fixed

- Improved adapter element-click validation for Avalonia, Uno, and WinForms.
- Stopped visual tree snapshot traversal when the configured node budget is exhausted.
- Added Uno pointer coordinate validation for rasterization scaling.

## [1.0.0] - 2026-05-15

### Added

- Initial NuGet package metadata for the broker, contracts, and adapter projects.
- GitHub Actions workflows for CI, CodeQL, NuGet releases, and demo releases.
- Initial plan
